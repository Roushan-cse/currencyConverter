# Currency Converter

A modern Currency Converter web application built using HTML, CSS, and JavaScript. The application allows users to convert between multiple currencies in real time using exchange rate data from a currency API.

The user interface features a premium glassmorphism design inspired by Apple's modern UI, including frosted glass effects, transparency, smooth animations, and vibrant gradient reflections.

## Features

* Real-time currency conversion
* Support for multiple international currencies
* Live exchange rates fetched from an API
* Modern Apple-inspired glassmorphism UI
* Responsive and user-friendly design
* Smooth animations and hover effects
* Built with pure HTML, CSS, and JavaScript (no frameworks)

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Fetch API

## How It Works

1. Select the source currency.
2. Select the target currency.
3. Enter the amount to convert.
4. The application fetches the latest exchange rates from the API.
5. The converted amount is displayed instantly.
